# Лабораторна робота 1 - Проект з C#

## Опис
Груповий проект з 4 учасників для демонстрації роботи з Git та GitHub.

## Структура проекту
- `src/` - вихідний код
- `tests/` - тести

## Учасники
1. Учасник 1 - налаштування репозиторію
2. Учасник 2 - створення C# проекту
3. Учасник 3 - бізнес-логіка
4. Учасник 4 - тести
